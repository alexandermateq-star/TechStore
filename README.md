## 📝 Descripción del Proyecto
Aplicación de escritorio desarrollada en Java con interfaz gráfica Swing para automatizar el registro, consulta y actualización de productos, así como la generación de ventas de la tienda "TechStore Local". Soluciona la problemática de registros manuales, errores de cálculo y desactualización de stock.

## 🏗️ Arquitectura y Patrones
El proyecto fue desarrollado aplicando el patrón de diseño **MVC (Modelo-Vista-Controlador)**:
- **Modelo (`src/modelo`):** Clases `Producto`, `Venta`, `Inventario`. Manejo de `ArrayList`, encapsulamiento y lógica de negocio.
- **Vista (`src/vista`):** Formularios Swing (`JFrame`, `JPanel`), uso de Layouts (`BorderLayout`, `GridLayout`) y `JTable`.
- **Controlador (`src/controlador`):** Implementación de `ActionListener` para eventos, validaciones lógicas y manejo de excepciones con `try-catch-finally`.
